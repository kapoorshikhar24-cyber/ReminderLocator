# GeoRemind Android APK (v2)

This folder contains the compiled, ready-to-install Android APK for **GeoRemind**.

## Files
- **[`GeoRemind-v2.apk`](file:///d:/Location/v2/GeoRemind-v2.apk)** (5.14 MB) — Latest compiled native APK.
- **[`GeoRemind.apk`](file:///d:/Location/v2/GeoRemind.apk)** (5.14 MB) — Direct alias for quick installs.

## How to Install Directly on Your Android Phone

1. **Transfer the APK to your phone**:
   - Send via WhatsApp / Telegram / Google Drive / Email, or
   - Connect phone via USB cable and copy `GeoRemind-v2.apk` into your `Downloads` folder.
2. **Open the APK on your phone**:
   - Tap the APK in your file manager or notification panel.
   - If prompted with *"Install unknown apps"*, toggle **Allow from this source**.
3. **Open GeoRemind & Grant Permissions**:
   - **Location**: Select **"Allow all the time"** (for background proximity alert triggers).
   - **Notifications**: Tap **Allow** (to receive alerts when entering reminder zones).
